## Repository Overview

**awesome-chatgpt-prompts** is a curated, community-driven collection of prompts for use with ChatGPT and other large language models. It is one of the most-starred prompt repositories on GitHub.

- **Website**: [prompts.chat](https://prompts.chat) (GitHub Pages, custom domain via `CNAME`)
- **Dataset**: Also published on [Hugging Face](https://huggingface.co/datasets/fka/awesome-chatgpt-prompts/)
- **License**: CC0 / MIT (see `LICENSE`)
- **Primary maintainer**: [@f](https://github.com/f)

## Key Files

### `README.md`
- The single source of truth for all prompts — ~158 prompts as of the latest commit.
- Each prompt follows this exact Markdown structure:

  ```markdown
  ## Act as a <Role>
  Contributed by: [@username](https://github.com/username)

  > The prompt text goes here as a blockquote.
  ```

- If the prompt was AI-generated, append `<mark>Generated by ChatGPT</mark>` to the "Contributed by" line.
- Prompts should start with "I want you to act as..." phrasing.

### `prompts.csv`
- Structured counterpart to `README.md`. Must be kept in sync with README entries.
- Format: two columns — `act` and `prompt`.
- Header row: `"act","prompt"`
- **CSV formatting rules (strictly enforced by CI)**:
  - Quotes within prompt text must be escaped by doubling them: `""like this""`
  - No space after commas between quoted fields: `"act","prompt"` not `"act", "prompt"`
  - No trailing whitespace on any line
  - `act` column should **not** include "Act as" prefix (e.g., use `"Linux Terminal"` not `"Act as a Linux Terminal"`)

### `_config.yml`
- Minimal Jekyll config: sets the site name to "Awesome ChatGPT Prompts".
- GitHub Pages renders `README.md` as the homepage using the `default.html` layout.

### `_layouts/default.html`
- Custom Jekyll layout with:
  - Google Analytics (gtag.js, ID: `G-MSNHFWTE77`)
  - Google AdSense
  - anchor-js for heading links
  - JavaScript that makes blockquotes under `## Act as` headings editable and adds a clipboard copy button (✂️)

## CI/CD — GitHub Actions

### `.github/workflows/csv_linter.yml`
Runs on every push and pull request. It:
1. Installs `csvkit` (Python 3.8)
2. Runs `csvclean -n -u 2` on all `.csv` files — validates proper CSV structure with double-quote escaping
3. Fails if any CSV errors are found
4. Checks `prompts.csv` for trailing whitespace — fails if any line has trailing spaces/tabs

**Before opening a PR, always verify:**
```bash
pip install csvkit
csvclean -n -u 2 prompts.csv
grep -P "\s+$" prompts.csv  # Should return nothing
```

## Development Workflow

### Adding a New Prompt

1. **Create and test** the prompt with ChatGPT or another LLM to confirm it works.
2. **Edit `README.md`** — add a new section using the standard template:
   ```markdown
   ## Act as a <Role>
   Contributed by: [@yourusername](https://github.com/yourusername)

   > Your prompt text here.
   ```
3. **Edit `prompts.csv`** — append a new row:
   ```csv
   "Role Name","Your prompt text here. Escape ""quotes"" by doubling them."
   ```
4. **Validate the CSV** before committing (see CI section above).
5. **Submit a pull request** to the `main` branch with a descriptive title and description.

### PR Requirements (from `.github/pull_request_template.md`)
- [ ] Prompt has been confirmed to work
- [ ] Added `Contributed by: [@yourusername](https://github.com/yourusername)` line
- [ ] Added to `README.md` following the template
- [ ] Added to `prompts.csv` with proper escaping, no trailing spaces, no space after commas

## Conventions and Rules for AI Assistants

### When modifying `README.md`
- Maintain alphabetical or thematic order is **not enforced** — new prompts are typically appended.
- Always use blockquote syntax (`>`) for the prompt text.
- Section headings must start with `## Act as` to be picked up by the JavaScript copy button in the web UI.
- Do not alter existing prompts without explicit instruction — these are community contributions.

### When modifying `prompts.csv`
- The CSV uses Unix line endings (LF). Do not introduce Windows line endings (CRLF).
- Always double-check that inner quotes are doubled, not backslash-escaped.
- Do not add spaces after commas separating fields.
- Verify no trailing whitespace is introduced (the CI will catch this and block the PR).

### General
- Do not modify `_layouts/default.html` or `_config.yml` unless specifically asked — these control the public website appearance.
- Do not rename or restructure core files (`README.md`, `prompts.csv`) — downstream tools and the Hugging Face dataset depend on their exact names.
- Contributions should go to `main` branch via pull requests from a personal fork, per `CONTRIBUTING.md`.
- The repository has no build system, package manager, test suite, or linter beyond the CSV GitHub Action — keep changes minimal and focused.

## No Local Development Setup Required

This is a content repository with no code to build or run. The only tooling needed is:

- **Git** — for version control
- **csvkit** (`pip install csvkit`) — only needed if validating CSV changes locally before push
- **A text editor** — for editing Markdown and CSV files

There is no `package.json`, `Makefile`, `Dockerfile`, or language runtime required.
